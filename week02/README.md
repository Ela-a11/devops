# Week 02 — Linux, Git and GitHub

## 1. Learning Objectives

During Week 02, I learned the fundamentals of Linux, virtualization, Git, and GitHub.

Topics covered:

- Virtualization: bare-metal servers, hypervisors, and containers
- WSL2 (Windows Subsystem for Linux)
- Basic Linux commands
- Git version control
- GitHub repositories and remote collaboration
- Branches and basic Git workflows

## 2. Linux Commands

| Command | Purpose |
|---|---|
| `pwd` | Shows the current directory |
| `ls` | Lists files and directories |
| `mkdir` | Creates a directory |
| `cd` | Changes the current directory |
| `touch` | Creates an empty file |
| `cat` | Displays file contents |
| `echo` | Prints text or writes text to a file |
| `cp` | Copies files or directories |
| `mv` | Moves or renames files |
| `rm` | Removes files or directories |

## 3. Git Commands

| Command | Purpose |
|---|---|
| `git init` | Initializes a Git repository |
| `git status` | Shows the current working-tree status |
| `git add` | Stages changes for a commit |
| `git commit` | Saves staged changes in the repository history |
| `git log` | Displays commit history |
| `git diff` | Shows changes between versions or working states |
| `git branch` | Lists or manages branches |
| `git switch` | Switches to another branch |
| `git push` | Uploads local commits to a remote repository |

## 4. Basic Git Workflow

```bash
git status
git add .
git commit -m "Describe the changes"
git push
```

This workflow checks the repository status, stages changes, creates a commit, and pushes commits to a remote repository. The exact push command depends on the branch and remote configuration.

## 5. Key Concepts

- **Git:** A distributed version control system that tracks changes to files.
- **GitHub:** An online platform for hosting Git repositories and collaborating.
- **Repository:** A project containing files and version history.
- **Commit:** A recorded snapshot of staged changes.
- **Branch:** An independent line of development.
- **Virtualization:** A way to run isolated computing environments using shared physical resources.
- **WSL2:** A Windows feature that provides a Linux environment.

## 6. Key Takeaways

Week 02 introduced the command line and version control workflow. I practiced navigating Linux directories, managing files, tracking changes with Git, and working with repositories and branches. These skills form the foundation for later DevOps practices.
